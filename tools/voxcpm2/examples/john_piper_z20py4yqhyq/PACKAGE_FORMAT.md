Production ZIP хранится как семь небольших файлов `package.part01.b64` … `package.part07.b64`. Launcher сортирует их по имени, проверяет количество и точную суммарную длину, объединяет, декодирует Base64, сверяет SHA-256 и только затем распаковывает. Разбиение устраняет риск обрезания одной очень длинной строки при записи через GitHub connector.
