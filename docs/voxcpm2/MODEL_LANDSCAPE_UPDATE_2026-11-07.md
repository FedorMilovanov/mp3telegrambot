# Локальные TTS-модели: дополнение к исследованию на 2026-11-07

Сводка реальных CPU-проб VoxCPM2, CosyVoice 3 и MOSS, состояния Higgs TTS 3 и новых кандидатов KittenTTS 2, MOSS-TTS-Nano, Fish Audio Drama 3; первичные источники, аппаратные ограничения и критерии безопасного внедрения.

**Статус:** исследование и реально выполненные локальные CPU-пробы; **не** решение о замене production backend. Историческое исследование: [MODEL_COMPARISON_2026-08-01.md](MODEL_COMPARISON_2026-08-01.md). Не переносить новые выводы задним числом на августовские замеры.

## Краткий результат

- **VoxCPM2** остаётся подтверждённой CPU-baseline для точечного исправления русской речи с референсом диктора. Два локальных варианта проверены технически; пользователь пока предпочитает их звучание.
- **CosyVoice 3 0.5B** теперь **реально опробована на CPU**, а не только GPU-кандидат: фраза произнесена, пользователь подтвердил приемлемое «Вместе ради Евангелия». Медленная генерация на нашем окружении не означает замедленное воспроизведение: скорость аудио можно менять отдельно.
- **MOSS-TTS v1.5 Q8 (большая модель)** технически синтезировала WAV, но пользователь услышал лишь бессмысленное «и читаталия» вместо заданного предложения. Это **контентный FAIL**, а не доказательство успешной TTS. Замечены знаки вопроса вместо кириллицы в выводе командной строки Windows; **возможная** ошибка кодировки требует воспроизведения через UTF-8 transport и ASR/ручной проверки. Не объявлять причину доказанной.
- **Higgs TTS 3 4B** имеет локальные веса, но успешного CPU-образца нет. Ранее CPU-тест дал несовместимость архитектуры Transformers; следующая попытка остановлена из-за требования не менее 20 ГБ свободной RAM. Не классифицировать как проверенный продакшен-движок.
- **KittenTTS 2, MOSS-TTS-Nano, русские PocketTTS/F5-тюнинги** — новые кандидаты для ограниченного A/B. Их качество на нашем дикторе пока **не проверено**.
- **Fish Audio Drama 3** — исследовательский потолок, **не текущая локальная замена**. Официальный путь: NVIDIA минимум 48 ГБ VRAM для FP8; CPU не поддерживается. Сторонний ComfyUI offload на 8–12 ГБ VRAM — **другая, экспериментальная реализация**, требующая существенной системной RAM и стабильной CUDA.

**Производительность на данном ПК:** CosyVoice 3 (CPU, 0.5B) синтезировала 5.12 с речи за ~273 с собственно inference (~297 с весь процесс). MOSS Q8 произвела 4.56 с WAV за ~66 с полного запуска, однако содержимое неверно. Скорости **нельзя** ранжировать независимо от правильности текста и разных режимов/референсов. Успешный exit code или отсутствие декодирующих ошибок — **не** свидетельство качественной речи.

### Fish Audio Drama 3: официальный и сторонний путь разделять всегда

- **Официальный** Fish Audio Drama 3: Mixture-of-Experts порядка **35B параметров, 3B active**, FP8 минимум **48 ГБ VRAM**, **NVIDIA-only**, Linux/WSL; штатного CPU path **нет**. Клонирование, многоголосие, editable speech и long-form поддерживаются, но по-русски на нашей записи не проверены.
- **Неофициальный** `PedroMarinhoDev/ComfyUI-Drama3`: выгрузка MoE experts в RAM, требования разработчика — NVIDIA **от 8 ГБ VRAM**, ~32 ГБ RAM для **W4A8** (файл ~24.6 ГБ + codec) либо ~48 ГБ RAM для INT8/FP8. Приведённые в репозитории 8/12 ГБ — **имитация лимита на RTX 3090**, а не наш эксперимент на RTX 3060; не переносить скорость без фактического замера.
- На нашей RTX 3060 **были CUDA/драйверные сбои** (`nvlddmkm`, Event ID 153); 32 ГБ физической RAM обычно заняты другими агентами. **Не ставить эту модель на C:, не запускать W4A8 на текущей карте и не советовать покупать GPU**, пока нет независимой демонстрации достаточного прироста русского качества и проверенной лицензии.

## Следующая ограниченная волна тестирования

1. **Никаких full download в первой волне:** сверить дату upstream, доступность весов, отдельную лицензию весов, требования к RAM и способность обрабатывать русское слово по референсу.
2. Сначала один короткий текст; ссылки на Писание озвучивать явно как **книгу, главу и стих**, никогда как время суток.
3. Для A/B использовать неизменные: reference WAV, фразу, sampling version, target tempo, измерить CPU time, RAM peak, file size и ASR-WER/word coverage; human listening обязателен.
4. При тестировании MOSS отделить четыре причины отказа: **кодировка CLI/UTF-8 JSON**, sampling/stop, референс (clean vs noisy), checkpoint extras/codec. Вывод вопросительных знаков в Windows Console **не доказывает**, что на вход нейросети пришли именно '?'.
5. Только успешно проверенную модель можно обернуть в `SpeechBackend` с existing production capability gate. Добавление новой модели **не требует менять** production `semantic blocks`, timeline и checkpoints.
