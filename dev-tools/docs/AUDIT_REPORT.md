## 🟡 Средние баги

### M1. Dead code: дублирующийся обработчик `---` / `***` / `___`

**Файл:** `services/telegraph.py`  
**Строки:** 88-91 и 122-123

**Проблема:** Условие `if s in ("---", "***", "___")` на строке 88 содержит `continue` (строка 91), из-за чего идентичный `elif` на строках 122-123 никогда не выполняется.

```python
# Строка 88 (выполняется):
if s in ("---", "***", "___"):
    nodes.append({"tag": "hr"})
    prev_was_empty = False
    continue

# Строка 122 (НИКОГДА):
elif s in ("---", "***", "___"):
    nodes.append({"tag": "hr"})  # мёртвый код
```

**Фикс:** Удалить строки 122-123.

---

### M2. Dead code: `else` в numbered list

**Файл:** `services/telegraph.py`  
**Строки:** 133-177

**Проблема:** Регулярное выражение `(.*)` на строке 134 захватывает пустую строку, поэтому `num_m` никогда не `None`. Ветка `else` на строке 176 — мёртвый код.

```python
elif re.match(r'^\d+\.\s', s):
    num_m = re.match(r'^(\d+)\.\s+(.*)', s)  # (.*) матчит пустую строку
    if num_m:  # ВСЕГДА True
        ...
    else:      # НИКОГДА
        nodes.append(...)  # мёртвый код
```

**Доп. эффект:** При "1. " (номер без текста) создаётся `<b>1. </b>` с пустым содержимым.

**Фикс:** Убрать `else`-ветку или изменить регулярное выражение на `(.*?)` с проверкой длины.

### M3. Синхронный SQLite в async-контексте (Shorts)

**Файл:** `pipelines/shorts.py`  
**Строка:** 312

**Проблема:** `short_trim_save()` выполняется напрямую без `run_in_executor()`, блокируя event loop. В `handlers/callbacks.py` (строка 373-393) та же операция обёрнута в executor — несоответствие.

```python
# pipelines/shorts.py:312 — синхронный вызов SQLite
short_trim_save(
    short_id=short_id,
    video_path=str(current_path),
    ...
)
```

**Фикс:** Обернуть в `loop.run_in_executor()`:

```python
loop = asyncio.get_running_loop()
await loop.run_in_executor(None, lambda: short_trim_save(...))
```

### M4. Синхронный SQLite в `finally` (Clips)

**Файл:** `pipelines/clips.py`  
**Строка:** 215

**Проблема:** В `finally` используется синхронный `settings_get()`, блокирующий event loop. В `pipelines/shorts.py` (строки 112-114) эта же проблема решена правильным чтением настроек заранее.

```python
finally:
    _clips_keep = settings_get("shorts_montage") or settings_get("shorts_highlights")
```

**Фикс:** Перенести чтение настроек в тело `try`.

## 🟢 Лёгкие баги / Code Smell

### L1. Дублирование `_fix_json_newlines`

**Файлы:** `services/telegraph.py` (строки 608-618) и `services/telegraph_pages.py` (строки 626-641)
