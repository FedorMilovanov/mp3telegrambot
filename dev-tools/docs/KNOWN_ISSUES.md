## 🟡 P2 — Косметика

### Telegraph: иногда "Cocoon AI" вылазит в коротких конспектах
- **Корневая причина:** Telegraph подставляет служебный текст когда контент <1000 символов
- **Текущий обход:** промпт явно запрещает мета-маркеры
- **Реальное решение:** удостовериться что Reflection/Study всегда полноценные (не fallback). Решено в `fix_ultimate_3_5_flash.py` через multi-model fallback.
- **Если повторится:** проверить лог — Reflection упал в fallback? значит multi-model fallback не сработал, Gemini глухо лежит.

### Жирные АБЗАЦЫ в Telegraph
- **Где:** в `services/telegraph.py:_md_to_telegraph_nodes` иногда `**...**` превращается в жирный целого абзаца если Gemini вернул `**длинный текст**`
- **Корневая причина:** 3.5-flash больше любит markdown чем 2.5
- **Решение в `2026-05-20_deep_quality.patch`:** `_demote_paragraph_bold` — если `<b>` занимает >70% строки → понижаем до обычного текста + жирные слова сохраняем точечно

### RuTube листинг иногда падает с timeout
```
RuTube листинг стр.51 ошибка: HTTPSConnectionPool... Read timed out
```
- **Причина:** RuTube API нестабилен через прокси
- **Импакт:** альт-ссылка иногда не находится — но это не блокер, видео всё равно публикуется
- **Действие:** оставить как есть, retry уже встроен

## ⚪ Заметки для будущего

### Возможные оптимизации (не баги, но улучшения)

1. **Кэширование `_gemini_text_request` ответов** — если за день один и тот же видео ID обрабатывается дважды (бывает при перезапуске бота), второй раз можно не звать Gemini.
2. **Параллельные модели вместо последовательных** — `asyncio.wait(..., return_when=FIRST_COMPLETED)` чтобы первая успешная модель завершала, остальные cancel'ились. Но это сложнее и для free tier рискованно.
3. **Поддержка `gemini-3.5-pro`** — выйдет в июне 2026. Когда выйдет, добавить в fallback с приоритетом 0 (выше чем flash).
4. **Streaming generate_content** — для длинных ответов начинать обрабатывать частично, не ждать весь JSON. Сейчас ждём всё.

### Рисковые места кода (внимательно при правках)

- `core/json_parser.py` — устойчивый парсер обрезанных JSON. Сложная логика восстановления, не упрощать.
- `core/core_utils.py:_fix_rtl_in_text` — RTL-обработка. Тонкая логика, тесты в проде.
- `services/telegraph.py:_md_to_telegraph_nodes` — markdown→nodes с обработкой нумерации, жирных заголовков, RTL. Менять с тестами на 3-5 видео разных типов.
- `pipelines/main_pipeline.py:577-650` — главный `asyncio.gather` всех пайплайнов. После `deep_quality.patch` Study+Reflection вынесены наружу, остальные остаются параллельными.
