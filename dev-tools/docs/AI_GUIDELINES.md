## 🎯 О проекте кратко

**Что это:** Telegram-бот, который превращает YouTube-видео (проповеди, лекции, Q&A) в:
1. **Конспект** в Telegraph (через Gemini-анализ аудио)
2. **Caption** в Telegram с таймкодами, ссылками на платформы, хэштегами
3. **Shorts** (вертикальные клипы 60-90с с субтитрами через Whisper)
4. **Разбор материала** (StudyAnalysis) — глубокое богословско-экзегетическое досье
5. **Размышление и применение** (ReflectionApplication) — пасторская рефлексия

**Тип юзкейса:** 1-5 видео в день. Главное — **качество**, не пропускная способность.

**Стек:** Python 3.13, google-genai 1.67+, python-telegram-bot, Flask, faster-whisper, SQLite.

## 🚨 Критичные инварианты (НЕ ЛОМАТЬ)

### 1. Промпты в `core/prompts.py` — НЕ ТРОГАТЬ без явной просьбы

Промпты огромные (~210KB) и тщательно настроены под:
- Запрет галлюцинаций (правила НЕОПРЕДЕЛЁННОСТИ и ФАКТИЧНОСТИ)
- Запрет дублирования полей (main_topic ≠ analysis_summary ≠ argument_arc)
- Запрет мета-маркеров ("Cocoon AI Summary", "AI Summary")
- Запрет канцелярита и пересказа
- Режимы плотности (deep / balanced / fast) с автокоррекцией под длительность

Если нужно поправить промпт — спрашивай разработчика прямо: "разрешишь править prompts.py?"

### 2. Структура JSON-ответа Gemini — НЕ МЕНЯТЬ

Ответ Gemini имеет фиксированную схему (см. `core/json_parser.py`):
```
{
  "real_author", "real_title", "real_event", "format",
  "main_topic", "timestamps": [{"time", "topic"}, ...],
  "hashtags": [...], "analysis_summary", "argument_arc",
  "key_categories": [...], "terms_data": {...}
}
```
БД, caption, telegraph — всё завязано на эту схему. Менять без crawl-rebuild импактных мест **запрещено**.

### 3. Кэш видео в SQLite — версионирован

В `bot_cache.db` поле `video_cache.model_name` хранит модель, на которой сделан анализ. При смене модели в `.env` кэш автоматически инвалидируется. **Не убирай** проверку `cache_version`/`prompt_version`/`model_name` из `db_get`.

### 4. Список бесплатных Gemini моделей с аудио (на май 2026)

| Модель | Free RPD у пользователя | Аудио | Качество |
|---|---|---|---|
| `gemini-2.5-flash` | 20 | ✅ | средне |
| `gemini-2.5-flash-lite` | 20 | ✅ | слабее |
| `gemini-3-flash` | 20 | ✅ | хорошо |
| `gemini-3.5-flash` ⭐ | 20 | ✅ | **отлично** (текущая) |
| `gemini-3.1-flash-lite` | 500 | ✅ | для fallback |
| ~~gemini-2.5-pro~~ | 0 | — | **НЕТ free для этого юзера** |
| ~~gemini-3.1-pro~~ | 0 | — | только платная |

**Не предлагай** Pro-модели как бесплатные — у этого аккаунта они недоступны.

### 5. Особенности `gemini-3.5-flash` (релиз 19 мая 2026)

- ⚠️ `thinking_level="medium"` по умолчанию — **слабее** чем у `gemini-3-flash-preview` с дефолтом `high`
- ✅ Для качества нужен явный `thinking_level="high"` в `ThinkingConfig`
- ⚠️ Параметр `thinking_budget` (int) **deprecated**, использовать `thinking_level` (string enum)
- ⚠️ Google рекомендует **НЕ переопределять** `temperature` на 3.x — defaults тюнингованы
- ✅ `max_output_tokens=40000` оптимум (high-thinking занимает 10-30K токенов)
- ❌ Не поддерживает Live API, Computer Use, image/audio generation
- ✅ Поддерживает audio input, structured output, function calling
- Цена (платно): $1.50/$9.00 per 1M tokens, кэш $0.15

### 6. Free tier Gemini хрупкий — нужен defensive код

- 503 "high demand" — норма в пиковые часы (14:00-23:00 UTC)
- Параллельные запросы к Gemini на free tier **запрещены** (быстро ловишь 503)
- Все Gemini-вызовы должны иметь:
  - Multi-model fallback (3.5-flash → 3-flash → 3.1-flash-lite)
  - Retry с exponential backoff (15s → 30s)
  - Логирование `type(e).__name__: str(e)[:200]`
  - `finish_reason` логирование

### 7. Иврит/RTL — уже исправлено, не трогать

В `core/core_utils.py:_fix_rtl_in_text` и в `services/telegraph.py:_md_to_telegraph_nodes` есть **отдельная обработка** RTL-текста через `dir="ltr"` на `<p>`/`<blockquote>`. Это работает. Не убирай атрибут `attrs["dir"] = "ltr"` при обнаружении `[\u0590-\u05FF\u0600-\u06FF]`.

## 🎨 Визуальные требования к выводу

### Telegram caption (build_caption в `converters/caption.py`)

✅ **Должно быть:**
- Шапка с эмодзи перед каждой строкой (📜 событие, 📖/📜 название, 👤 автор)
- Пустая строка между блоками (header → topic → таймкоды → ссылки → хэштеги)
- **Жирные** ключевые слова в `main_topic` (через `**...**` от Gemini → `<b>` HTML)
- Таймкоды как кликабельные ссылки на YouTube с этим timestamp'ом
- **Пробел** между ссылкой-таймкодом и темой: `[0:00](url) Тема`
- Эмодзи перед заголовками блоков: `⏱ Таймкоды:`, `📂 Читать Подробный Разбор:`, `Смотреть Видео:`

✅ **Можно** (по новому требованию пользователя):
- **Жирные** важные/интересные слова прямо в темах таймкодов — для визуальной читаемости

❌ **НЕ должно быть:**
- Markdown `**` в видимом тексте (Gemini-артефакты должны чиститься)
- "Cocoon AI Summary", "AI Summary" — мета-маркеры запрещены
- Слипание `⏱Таймкоды` (без пробела после эмодзи)
- Двойные/тройные пустые строки (только одна между блоками)
- Лишние точки от Gemini как разделители

### Telegraph-страницы (Конспект, Разбор, Размышление)

✅ **Должно быть:**
- Заголовки h3/h4 для секций
- Жирные подзаголовки `<b>` для ключевых пунктов внутри секций
- Нумерованные секции через `1.` `2.` `3.`
- Блок `📂 Читать также: ...` внизу с навигацией между 3 страницами
- Корректный RTL для еврейского/арабского текста (`dir="ltr"` на параграфе)
- Списки `<ul>/<ol>` для перечислений
- Цитаты Писания в `<blockquote>`

❌ **НЕ должно быть:**
- Markdown `**`, `*`, `_` в видимом тексте (всё должно конвертироваться в теги)
- Подряд `<b>Title</b><b>Text</b>` (должно сливаться в один тег)
- Жирные АБЗАЦЫ (только короткие слова/фразы)
- Пустые секции / секции с одним заголовком
- "Cocoon AI" — Telegraph подставляет когда контент слишком короткий → нужно делать контент длиннее

## 🔧 Технические правила

### При смене модели Gemini

1. Обновляй `make_audio_config` и `make_text_config_smart` в `core/globals.py`
2. Если 3.x → ставь `thinking_level="high"` для качества
3. Проверяй кэш — после смены модели старые записи перестают использоваться (автоматически)
4. Добавляй модель в whitelist в `main.py` (если warning мешает)

### При работе с Gemini API

✅ Всегда:
- Использовать File API upload (НЕ inline) для аудио — иначе 503 на больших файлах
- Логировать `finish_reason` (особенно `MAX_TOKENS`)
- Использовать `make_audio_config()` / `make_text_config_smart()` — не `GenerateContentConfig` напрямую
- Multi-model fallback: 3.5 → 3 → 3.1-flash-lite (для аудио и текста)

❌ Никогда:
- `asyncio.gather` для **двух и более Gemini-вызовов параллельно** — каскадные 503
- inline base64 для аудио — превышает 20MB лимит
- `thinking_budget` (int) — deprecated, использовать `thinking_level` (string)
- `audio_timestamp=True` — не поддерживается в google-genai 1.x

### При работе с Telegraph

- HTML-сущности экранировать через `html_mod.escape()`
- Перед публикацией прогонять через `_md_to_telegraph_nodes()` если контент markdown
- Навигация "Читать также" добавляется через `editPage` ПОСЛЕ публикации всех трёх страниц
- `_md_parse_inline()` отвечает за inline-разметку (жирный, ссылки) — менять осторожно

### Cleanup

После применения патча или фикса:
1. Удалить `*.bak_*` файлы из репо (через `dev-tools/scripts/cleanup_backups.ps1`)
2. Удалить `bot_cache.db-shm`, `bot_cache.db-wal` (они в `.gitignore` должны быть)
3. Сам .py-патч **не коммитить** в корень — переносить в `dev-tools/patches/` как .patch
4. Записать в `dev-tools/docs/CHANGELOG_PATCHES.md` что и зачем делал
