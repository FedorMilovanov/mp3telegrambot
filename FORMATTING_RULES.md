# Правила форматирования Telegraph-страниц
> Источник истины для промптов и постобработки.
> Последнее обновление: 2026-05-25

---

## 1. Общие правила

- Не начинать section после `h3` с эмодзи-ярлыка: `🔑`, `📖`, `🏛️`, `⚖️`, `📚`, `📜`, `🛡️`, `🗣️`.
- Не делать «лесенку» из эмодзи, пустых маркеров и служебных префиксов.
- Внутри section использовать обычные маркеры `•` или `-`.
- Заголовки section (`title`) — без эмодзи.
- Таймкод в тексте: `... [⏱ 5:32](url).` — внутри предложения, перед точкой.
- Формат времени: `5:32`, не `05:32`.
- Диапазоны стихов: `18:15–17`, без пробелов вокруг тире.

## 2. Study Analysis

### SECTION TYPE 1 — Ключевые понятия

Формат каждой карточки:

```text
• **Суверенная благодать** (**Sovereign Grace**) — определение и богословская значимость.
```

Правила:
- у каждой карточки есть обычный маркер `•`
- после маркера сразу идёт жирный термин
- без эмодзи перед карточкой
- без сплошного потока абзацев без маркеров

Ёлочки нужны только у буквальных калек:

```text
• **«Лёгкое верие»** (**Easy Believism**) — ...
• **«Спасение господством»** (**Lordship Salvation**) — ...
• **«Возраст ответственности»** (**Age of Accountability**) — ...
```

Без ёлочек:

```text
• **Суверенная благодать** (**Sovereign Grace**) — ...
• **Первородный грех** (**Original Sin**) — ...
• **Фарисейский легализм** (**Pharisaic Legalism**) — ...
```

### SECTION TYPE 2 — Ключевые тексты

Формат каждого блока — в одну строку:

```text
• **Луки 18:15–17:** *«Приносили к Нему и младенцев, чтобы Он прикоснулся к ним...»*
```

Правила:
- ссылка жирная
- после ссылки двоеточие
- цитата курсивом в «ёлочках»
- без точки после цитаты
- не переносить ссылку и цитату на разные строки
- не делать `📖 **•** Луки ...`

### Параллельные места

Нельзя делать сухое перечисление:

```text
❌ → Иова 3:11–19; Псалом 22:10–11.
```

Нужно делать умный связный абзац:

```text
Ту же тему с другой стороны раскрывает Иов 3:11–19 (*«почему не умер я»*), где звучит боль перед тайной смерти и человеческой немощи. Псалом 22:10–11 (*«на Тебя оставлен я от утробы»*) добавляет мотив ранней зависимости от Бога, поэтому вместе эти места не просто перечисляют похожие слова, а освещают вопрос детства, смерти и Божьего покрова под разными углами.
```

### SECTION TYPE 7 — Карта источников

Формат:

```text
- Джон МакАртур, *Safe in the Arms of God*
Описание, зачем читать.
```

Правила:
- автор обычным шрифтом
- название книги курсивом
- не жирнить весь заголовок источника
- если нет устойчивого русского перевода, не выдумывать его

Неправильно:

```text
- **Джон МакАртур, «Спасение младенцев»...**
```

Правильно:

```text
- Джон МакАртур, *Safe in the Arms of God*
```

## 3. Reflection Application

### TYPE 2 — Смена парадигмы

Формат каждого пункта — один связный абзац:

```text
• **От спасения через духовную зрелость к принятию через абсолютную нужду.** Ибо мы привыкли думать, что спасение требует интеллектуальной зрелости, но Христос ставит в центр младенца и показывает, что вход в Царство совершается через *абсолютную беспомощность* (Absolute Helplessness).
```

Правила:
- жирным только первый тезис-подзаголовок
- текст после него логически вытекает из заголовка
- не делать второй отдельный блок после жирного начала
- термины внутри текста — в основном *курсивом* и строчными буквами
- не писать лишний Title Case: `*Суверенная Защита*` ❌ / `*суверенная защита*` ✅

### TYPE 3 — Диагностика сердца

Формат каждого пункта:

```text
**Когда ты в последний раз ставил барьер перед теми, кто мешает твоей «важной» работе?**

Ученики отгоняли родителей с детьми в момент серьёзного служения. Мы делаем то же самое, когда раздражаемся на тех, кто нарушает наш духовный комфорт. Кого ты прямо сейчас считаешь слишком малым для своего времени и внимания?
```

Правила:
- никакого `•` перед жирным вопросом
- строка с вопросом должна быть визуально выделена
- после вопроса идёт раскрывающий абзац, а не следующий голый вопрос
- никакого «простого комка текста» без структуры

### TYPE 6 — Предупреждения и контрасты

Формат:

```text
• **От паники к упованию на Божью заботу.** Поскольку мы склонны измерять любовь Бога уровнем своей тревоги, проповедь переводит нас от страха к доверию и учит смотреть на *возраст ответственности* (Age of Accountability) как на пастырскую категорию, а не на повод для паники.
```

Правила:
- только bullet-пункты
- без нумерации I. II. III.
- без пар `❌ / ✅`
- без тяжёлых терминов в жирном внутри основного текста
- если термин не является отдельным заголовком, лучше курсив и строчные буквы

### TYPE 7 — Молитвенный отклик

Формат:

```text
1. **Молитва о сокрушении самоправедности.** Господи, я прихожу к Тебе...
```

Правила:
- каждый пункт — живая молитва, не тезис
- 4–6 предложений
- без служебных эмодзи в заголовке пункта

## 4. Частые регрессии, которые нужно ловить

- `🔑 **Первородный грех** ...` — лишний эмодзи перед первым пунктом
- `📖 **•** Луки 18:15...` — эмодзи + жирный bullet
- `📚 **- Джон МакАртур...**` — жирный источник
- `→ Иова 3:11–19; Псалом 22:10–11` — тупое перечисление вместо живого абзаца
- standalone-вопросы без жирного и без раскрытия
- лишние заглавные буквы у понятий внутри абзаца
- выдуманные русские названия непереведённых книг
